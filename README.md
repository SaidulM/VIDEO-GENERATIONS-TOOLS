# Short Story Studio V2 — Colab-first video production

A notebook-native creator workspace for Short Story Speaker. This redesign learns from MoneyPrinterTurbo, Stickman Video Director, OpenMontage and HyperFrames, without requiring Claude Code or a local GPU.

## What V2 does

| Production task | Engine | Cost / requirements |
|---|---|---|
| Topic to script and storyboard | OpenRouter, Groq, Gemini, DeepSeek, OpenAI-compatible API | Provider-specific free tiers or paid APIs; key required |
| Pasted script to scene plan | Built-in scene splitter | No LLM key needed |
| Real stock footage | Pexels Video API / Pixabay Video API | Free API keys, provider quotas and terms apply |
| Motion graphics | HyperFrames + HTML/CSS/GSAP | Apache-2.0 open source; no per-render fee |
| Hindi/Bengali voice | Gemini 3.8 Flash TTS | Hosted service; free tier on eligible accounts, not open-source |
| Open-model TTS / voice clone | Chatterbox Multilingual V3 | Optional Colab GPU; research/retired upstream |
| Caption timing | Sentence estimate or Faster-Whisper tiny | Sentence estimate is keyless; Whisper adds a model download |
| Export | HyperFrames + FFmpeg | MP4, SRT, timestamp JSON, storyboard and credits manifest |

**Important:** this free-first V2 uses real stock clips plus code-generated motion graphics. Pexels/Pixabay footage is not generated by an AI model. The code-motion renderer is not text-to-video diffusion. We do not label it as photorealistic AI-generated footage. Truly generative video model APIs such as Veo, Kling, Seedance, Runway and hosted LTX endpoints generally require credits/billing or a separately managed GPU. They are not presented as unlimited free services.

## Start in Google Colab

Open the notebook:

https://colab.research.google.com/github/SaidulM/VIDEO-GENERATIONS-TOOLS/blob/studio-v2/notebooks/short_story_studio_v2.ipynb

Run notebook cells from top to bottom:

1. Clone the studio-v2 branch and install the lightweight dashboard dependencies.
2. Install Node 22+, FFmpeg and HyperFrames in the temporary runtime.
3. Optionally install Faster-Whisper for audio-aligned captions.
4. Optionally install Chatterbox V3 if you have a Colab GPU and want to test voice cloning.
5. Mount Google Drive if you want exports to persist between temporary Colab sessions.
6. Open the notebook-native dashboard.

The dashboard does not start a public web server. It exists in the notebook's interactive widgets; stop the runtime when finished. Free Colab GPU access is not guaranteed. Core LLM, stock and HyperFrames rendering can run in a CPU runtime, but Chatterbox voice cloning requires CUDA in this profile.

## Dashboard features

- Dark creator dashboard with separate Create, Scenes, Voice, Export and API/Models panels.
- Topic-only LLM planning or script-preserving scene splitting.
- Ten visual styles: cinematic, Islamic geometry, cyberpunk, hand-drawn, stickman, retro TV, pixel art, clay, 3D-inspired and kinetic typography.
- Editable narration, on-screen text, visual direction and stock search phrase for every scene.
- Dynamic model-list refresh and connection test for supported LLM providers; exact model ID override supported.
- Pexels/Pixabay stock search results and manual clip selection per scene.
- Gemini TTS voice/style selection and preview.
- Optional Chatterbox V3 voice cloning with explicit own/authorized voice consent.
- Optional background music upload.
- Editable caption style; estimated sentence timing or optional Whisper word-group timing.
- Final video player and export links.

## Model and API providers

- **OpenRouter:** free model catalog and openrouter/free router. Free quotas and model availability change.
- **Groq:** developer free-tier model access subject to account rate limits.
- **Gemini:** eligible Flash text models can have a free tier; some content sent through Google's free tier may be used to improve Google products.
- **Cloudflare Workers AI:** the Workers Free plan includes 10,000 Neurons per day. Add your Cloudflare Account ID in the Base URL and select a model such as @cf/meta/llama-3.2-1b-instruct. The daily allowance can run out; model usage consumes Neurons.
- **DeepSeek:** API access; do not assume the selected model is free.
- **Grok / xAI:** supported through the xAI API model catalogue; API usage is paid.
- **OpenAI:** paid API.
- **Custom:** any OpenAI-compatible endpoint with a manual URL and model ID.

The provider picker fetches the model list dynamically when the provider exposes that endpoint and tests the selected model with a small text request. If the service does not return a list, enter the exact model ID in the override field. It never silently changes to another model after an error.

## Voice

**Gemini 3.8 Flash TTS** is a hosted, high-quality option. It is not open-source. The eligible Gemini API free tier is quota-limited, and data sent through a free tier can be used to improve Google's products. Avoid submitting private or confidential scripts on that tier. Its voice catalog includes multiple preset speakers, and the UI allows a delivery/style prompt.

**Chatterbox Multilingual V3** is an experimental open-source model, not a hosted unlimited free service. It requires a Colab CUDA GPU in this implementation. Its upstream project is marked retired/no longer maintained. Voice cloning must use your own recording or a voice you have explicit permission to use, and must not be used for deceptive impersonation.

## Footage and licensing

Pexels and Pixabay provide stock search APIs. The studio adds a source, creator and credit URL to the project manifest. Pexels requires a prominent link to Pexels and encourages photographer credit; the dashboard displays Pexels and Pixabay links. Respect each provider's API limits, attribution rules, caching requirements and content licences. Download only the scene clips you approve.

## HyperFrames composition engine

The app writes timed HTML compositions with a root composition ID, width, height and frame rate. Timed visual, audio, stock-footage and caption elements have start, duration, track and clip attributes. A paused GSAP timeline is registered as the root timeline.

The renderer runs HyperFrames browser setup, composition linting and MP4 rendering. A failed lint or render ends the job with an explicit error; the renderer does not claim success or silently switch to a different model.

HyperFrames is Apache-2.0. Its CLI requires Node.js 22+ and FFmpeg. No HyperFrames model weights are downloaded.

## Security and privacy

- API keys entered in the dashboard exist only in the active Colab Python process memory; the dashboard does not write them to GitHub, notebooks, environment files or project output.
- Do not put provider API keys in notebook source cells or GitHub Secrets for this workflow.
- Google Drive voice samples persist after the runtime ends; only save them there if you want that.
- Do not upload or clone a third party's voice without consent.
- Check Colab's current usage policy before using voice identity matching or any synthetic impersonation workflow.

## Tests and limitations

GitHub Actions covers Python syntax and unit tests for script preservation, style/provider catalog, generated composition structure and stock URL validation. It does not validate external API keys, generate live audio, search Pexels/Pixabay, or run a Colab GPU render. Those require provider credentials and an actual Colab session.

The following are not included in this free-first V2:
- Unlimited photorealistic AI text-to-video generation.
- Unlimited free TTS or unlimited free LLM inference.
- Public always-on hosted UI.
- Automatic upload to YouTube.
